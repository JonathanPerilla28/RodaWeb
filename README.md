# Láminas y Aglomerados Roda S.A.S

Sitio web oficial de **RODA** — empresa dedicada a la venta, corte y canteo de láminas de aglomerado de madera arquitectónica en Fusagasugá, Cundinamarca.

## 🌐 Ver sitio en vivo

Una vez publicado en GitHub Pages, el sitio estará disponible en:  
`https://<tu-usuario>.github.io/RodaWeb/`

## 📁 Estructura del proyecto

```
RodaWeb/
├── index.html              # Página principal
├── _config.yml             # Configuración GitHub Pages
├── .nojekyll               # Evita procesamiento Jekyll innecesario
├── assets/
│   ├── css/
│   │   └── styles.css      # Estilos principales
│   ├── js/
│   │   └── main.js         # JavaScript interactivo
│   └── images/
│       └── logo/           # Logos de la empresa
└── README.md
```

## 🚀 Publicar en GitHub Pages

1. Sube el repositorio a GitHub
2. Ve a **Settings → Pages**
3. En **Source**, selecciona la rama `main` y carpeta `/ (root)`
4. Guarda y espera unos minutos
